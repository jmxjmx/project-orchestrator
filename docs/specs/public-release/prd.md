# 公开版发布规格

## 目标

将项目总编 Skill 整理为可独立上传到公共 GitHub 仓库的版本，同时保持 `SKILL.md`、参考规则和评测样本的行为语义。

## 必要需求

- FR-001：公开版不得包含旧仓库的 Git 历史、旧账号、提交邮箱、远程地址或标签。
- FR-002：公开版不得包含机器用户名、用户主目录、内部模型路由、账号冷却或发布提交记录。
- FR-003：公开版不得提供复制本机认证文件或 bearer token 的评测自动化。
- FR-004：README、LICENSE、`.gitignore` 和目录说明必须与新账号、公开仓库和当前文件结构一致。
- FR-005：保留不含真实秘密的评测定义、安全样本和确定性仓库自检。
- FR-006：公开版必须通过结构、JSON、链接、样本引用和隐私模式检查。
- FR-007：经用户明确授权后，在目标 GitHub 账号创建公共仓库并推送 `main`。

## 非目标

- 不复用源仓库的 Git 历史、标签或远程地址。
- 不推送任何旧提交。
- 不修改源 Skill 目录。

## 验收场景

- AC-001：全目录和全新 Git 元数据中检索不到旧账号、旧远程地址和机器用户路径。
- AC-002：`python scripts/validate_repo.py` 返回成功。
- AC-003：目标目录不包含 `scripts/run_evals.py`、`auth.json`、`config.toml` 或 `codex-home`。
- AC-004：README 中的安装地址指向当前发布账号，不指向旧账号。
- AC-005：公共仓库的默认分支为 `main`，远端提交与本地提交一致。
